What you can do

Five ways to run deepfake detection — all powered by the same 3-model ensemble.

Image Detection

Upload any JPG, PNG or WEBP. Get per-model scores, ensemble verdict and probability chart.

Video Detection

Frame-by-frame analysis of uploaded MP4/AVI/MOV. See AI probability timeline across all frames.

Batch Detection

Upload up to 50 images at once. Get individual results plus an aggregate summary with AI ratio.

YouTube VOD

Paste any YouTube URL. yt-dlp downloads it automatically and the ensemble analyses sampled frames.

Live Streams

Auto-detects YouTube live streams and captures frames in real-time for continuous ensemble scoring.

Analytics Dashboard

Tracks every detection locally. View verdict breakdown, file type split and scan volume over time.

About this project

AI-Driven Deepfake Detection is a final year B.Tech Computer Science & Engineering project (2025–26). It merges a ResNet50-based image/video detector with a YouTube pipeline (VOD + live streams) and a new batch processing endpoint — all served from a single unified Flask backend on Google Colab with GPU acceleration.
